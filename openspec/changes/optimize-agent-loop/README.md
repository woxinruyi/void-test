# 优化：Agent 循环效率提升（optimize-agent-loop）

## 摘要

针对 Void Agent 与 Codex CLI 的效率差距进行优化，解决以下核心问题：

1. **一次只能调用一个工具** → 启用并行工具调用
2. **系统提示词太弱** → 重写提示词（自主性、代码质量、计划纪律）
3. **工具结果无截断** → 中间截断策略（10K token 上限）
4. **无循环检测** → 添加循环检测 + 50 轮硬上限

## 预期效果

| 指标 | 优化前 | 优化后 |
|------|--------|--------|
| Token 消耗 | 500K-2M+ | 50K-200K |
| 任务完成率 | ~30% | ~70%+ |
| LLM 轮数 | 30-50+ | 10-20 |
