# 市场固定高度滚动容器能力（marketplace-fixed-scroll）

## ADDED Requirements

### Requirement: 市场列表区域固定高度滚动

`MarketplaceBrowser` 组件的搜索结果列表区域必须（SHALL）被包裹在一个固定最大高度的可滚动容器内，使其不会撑高整个设置页面。搜索栏、排序筛选栏、错误提示和"加载更多"按钮必须（SHALL）保持在滚动容器外部，始终可见。

#### Scenario: 结果列表超出容器高度时出现滚动条
- **WHEN** 市场搜索返回的卡片总高度超过容器最大高度（480px）
- **THEN** 容器内部出现垂直滚动条，用户可在容器内滚动浏览
- **THEN** 搜索栏和排序筛选栏保持在容器上方可见
- **THEN** "加载更多"按钮保持在容器下方可见

#### Scenario: 结果列表未超出容器高度时无多余空白
- **WHEN** 市场搜索返回的卡片总高度小于容器最大高度
- **THEN** 容器高度自动收缩适应内容，不出现多余空白区域

#### Scenario: 空状态和加载状态不受滚动容器影响
- **WHEN** 市场搜索无结果或正在加载中
- **THEN** 空状态提示和加载动画正常显示，不被滚动容器截断
