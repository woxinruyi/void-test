# 斜杠命令（slash-commands）

## ADDED Requirements

### 需求：聊天输入支持斜杠命令

系统 SHALL 在 Chat 输入层支持 `/<command>` 斜杠命令，命令来源聚合内置命令、已启用技能与工作区本地命令。

#### Scenario: 输入 `/` 弹出候选
- **WHEN** 用户在聊天输入框行首键入 `/`
- **THEN** 展示可用命令候选（名称 + 描述 + 来源），可补全选择

#### Scenario: 普通消息零回归
- **WHEN** 用户消息不以 `/<已注册命令>` 开头
- **THEN** 走改动前的原有发送流程，行为不变

### 需求：技能渐进式披露

系统 SHALL 仅在技能被斜杠命令显式调起时，将其完整正文注入本轮上下文；未调起时常驻系统提示只含技能描述。

#### Scenario: 调起技能加载正文
- **WHEN** 用户提交 `/<skill-name> ...`
- **THEN** 该技能完整正文作为本轮前置指令注入并影响输出

#### Scenario: 未调起不注入正文
- **WHEN** 某技能已启用但本轮未被调起
- **THEN** 该技能正文不出现在该轮请求体（仅描述常驻），可由注入断言/ token 计数验证

#### Scenario: 正文加载失败降级
- **WHEN** 技能正文按 URL 加载失败
- **THEN** 降级为仅使用其描述并提示用户，不中断对话

### 需求：本地自定义命令

系统 SHALL 识别工作区 `.void/commands/*.md` 为本地斜杠命令（front-matter 描述 + 正文模板）。

#### Scenario: 本地命令可用
- **WHEN** 存在 `.void/commands/foo.md` 且用户提交 `/foo`
- **THEN** 其正文模板被展开为本轮指令（支持 `$ARGS` 占位）

### 需求：内置命令

系统 SHALL 提供至少 3 个内置斜杠命令（如 `/plan` `/review` `/help`），其中纯本地命令（如 `/help`）不触发 LLM 调用。

#### Scenario: 纯本地内置命令
- **WHEN** 用户提交 `/help`
- **THEN** 本地渲染可用命令清单，不发起 LLM 请求
