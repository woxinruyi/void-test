## 三、约定

- **新过程性文档**：默认以 `temp-` 前缀命名，写在 `归档/` 或临时放 `根/` 后定期归档
- **定稿正式文档**：移出 `归档/`、去掉 `temp-` 前缀、进入根目录
- **OpenSpec change**：重大功能/架构变更一律走 `openspec/changes/<name>/` 流程（proposal / design / tasks / specs），本目录只做方案存底
